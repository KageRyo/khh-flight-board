# KHH Flight Board

在家中的螢幕查看高雄小港機場離站航班。正體中文介面，以紫色底、航空公司色帶與彩色航班卡片呈現資訊，適合 1080p / 4K 螢幕長時間展示。

這是可本機執行的 MVP。**使用官方公開 JSON 定期查詢，不是機場內部 FIDS 的秒級同步畫面。** 尚未取得可確認的「2025 年現場彩色卡片」原始參考圖片，因此目前是風格重現，不宣稱 100% 還原。

![1080p 航班卡片預覽；航班為截圖當時資料](docs/preview.png)

## 啟動

安裝 [Node.js](https://nodejs.org/) **22.19 或更新版本**，在專案資料夾開啟終端機：

```sh
git clone https://github.com/KageRyo/khh-flight-board.git
cd khh-flight-board
npm start
```

開啟 **http://127.0.0.1:3000**。不需要 API 金鑰、套件安裝或編譯。維持終端機開啟；按 `Ctrl+C` 停止。

Windows 也可以在已安裝 Node.js 後，雙擊 `start-board.cmd`。

## 功能

- 國際線預設顯示，也可切換國內線；兩組資料與快取彼此獨立。
- 航空公司名稱、官方圖示、航班編號、目的地與機場代碼。
- 表定時間、預計／實際時間、登機門、官方原始狀態與延誤原因。
- 每 60 秒自動查詢；失敗後持續按同一間隔重試，回復連線時重新查詢。
- 最後成功取得時間、資料年齡、快取及資料錯誤提示。
- 後端磁碟快取與瀏覽器快取，更新失敗時保留最後成功清單。
- 桌面每頁 12 張卡片，每 18 秒自動翻頁；可暫停及手動翻頁。
- 搜尋航班、航空公司或目的地，篩選全部／未離站航班。
- 全螢幕按鈕（瀏覽器不支援時可按 `F11`）、手機版單欄卡片。
- 支援鍵盤操作、可見焦點與減少動態效果設定。

## 設定

複製 `.env.example` 為 `.env`，修改後重新啟動。例如：

```dotenv
HOST=127.0.0.1
PORT=3000
POLL_SECONDS=60
UPSTREAM_TIMEOUT_SECONDS=12
```

| 設定 | 預設 | 範圍／用途 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 僅本機連線 |
| `PORT` | `3000` | 1–65535，若被占用可改為 3001 |
| `POLL_SECONDS` | `60` | 30–3600 秒，前端與代理共用 |
| `UPSTREAM_TIMEOUT_SECONDS` | `12` | 2–25 秒，上游連線逾時 |

如需在家中另一台裝置查看，可自行將 `HOST` 設為 `0.0.0.0`，並使用這台電腦的區網 IP 與設定的連接埠。MVP 沒有帳號或公開服務設計，預設只監聽本機。全螢幕 API 是否可用取決於瀏覽器及安全環境。

## 資料來源與欄位

- [官方國際線離站 JSON](https://www.kia.gov.tw/Announce/NewsArea/InstantSchedule_INTDEP.json)
- [官方國內線離站 JSON](https://www.kia.gov.tw/Announce/NewsArea/InstantSchedule_DOMDEP.json)

瀏覽器透過同源 `/api/flights?source=int` 或 `source=dom` 取得資料，由 Node.js 代理連線至固定官方網址，避免瀏覽器 CORS 問題。官方 Logo 直接從官方 `/images/` 載入，失敗時仍顯示航空公司名稱。

| 官方欄位 | 看板呈現 |
| --- | --- |
| `expectTime` | 表定時間 |
| `realTime` | 原始異動時間；狀態為離站／起飛時標示「實際」，其他狀態標示「預計」 |
| `airLineName`, `airLineCode`, `airLineNum` | 航空公司名稱、ICAO 識別及完整航班文字 |
| `goalAirportName`, `goalAirportCode` | 目的地名稱與機場代碼 |
| `airBoardingGate` | 登機門 |
| `airFlyStatus`, `airFlyDelayCause` | 官方原始狀態及原因，不以時間差自行判斷延誤 |
| `checkInIsland`, `checkInDeskRange` | 國際線櫃台，原樣保留上游文字 |

缺值顯示 `—` 或「尚未提供」，未知狀態原樣顯示。共掛航班文字與各資料列均保留，不猜測合併。依表定時間排序，不因目前時鐘而自行刪除航班；可用篩選隱藏已離站資料。

**資料日期限制：** 目前 JSON 沒有提供航班日期、時區、來源發布時間或資料版本。畫面統一使用台灣時間（Asia/Taipei）；頁首日期是現在日期，不能證明清單屬於該日。「最後成功取得」是本機成功連線、解析及驗證資料的時間，**不代表官方最後更新時間**。即使重新取得相同內容，也無法確認上游是否仍新鮮。跨日保留的快取會顯示完整取得日期與資料年齡，不會重新指定航班日期。行程請以機場及航空公司公告為準。

## 更新、錯誤與快取

前端在每次請求完成後等待設定秒數再查詢，因此網路耗時會增加實際間隔。背景分頁可能被瀏覽器降速；切回分頁會再次查詢。代理以「資料來源」為單位合併並行請求，距上次嘗試不足輪詢間隔時回傳現有結果；按「更新」也遵守此限制。沒有開啟看板或 API 請求時，不會額外定時抓取上游。

1. 成功取得且結構有效：更新記憶體、`.cache/int.json` 或 `.cache/dom.json`，再保存至瀏覽器 `localStorage`。
2. 官方逾時、非成功 HTTP、無效 JSON 或任一航班必要欄位異常：不覆蓋最後成功資料，顯示錯誤與快取提示。
3. 合法空陣列 `[]`：視為成功，清除舊航班並顯示「官方目前未提供航班」。
4. 代理停止或網路中斷：已開啟的頁面保留航班，下一次查詢失敗時顯示錯誤。重新啟動代理後，也可從磁碟快取復原。
5. 本機快取超過兩個輪詢間隔未成功取得資料時，標為快取；不會把錯誤嘗試時間當作成功時間。磁碟或瀏覽器寫入失敗會提示，線上資料仍可顯示。

**斷線範圍：** 沒有 Service Worker；若本機代理已停止，重新整理整個頁面將無法載入網頁。請先重新啟動 `npm start`。Logo 不提供離線快取，但航空公司文字始終保留。清除專案 `.cache/` 與網站儲存空間可重置所有快取。

## 驗證與開發

```sh
npm test
npm run check
```

測試包含真實欄位解析、缺值、未知狀態、共掛文字、排序、空清單、損壞回應、更新失敗、並行請求、重試節流及磁碟復原。上游回應在測試中以可控輸入代替，不依賴當天網路狀態。GitHub Actions 會在 Windows 與 Linux 執行相同檢查。

```text
server.mjs          固定來源 API 代理與靜態檔案伺服器
lib/feed.mjs        更新節流、逾時、資料驗證與磁碟快取
public/model.mjs    共用資料正規化及快取驗證
public/app.mjs      卡片、搜尋、輪播、更新與瀏覽器快取
public/styles.css   紫色卡片、航空公司色帶與響應式排版
test/               Node.js 原生測試
```

目前配色是本專案選定的航空公司辨識色，並非宣稱官方品牌標準色。官方 Logo 與航班資料權利屬原權利人；本專案程式碼依 [MIT License](LICENSE) 授權。
