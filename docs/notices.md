## 整合

頁面載入 `marquee.css`，以 `mountMarquee(document.querySelector('#marquee'))` 掛載在既有歡迎詞容器。模組只讀取同目錄的 `notices.json`，使用 DOM 節點與 `textContent` 呈現文字；網路錯誤、格式錯誤或無有效項目時保留原歡迎詞。`setPaused(true)` 停止動畫並讓完整文字可水平捲動，`destroy()` 還原原內容並取消載入及尺寸監測。

正常模式使用 CSS 連續捲動，重複段落對輔助科技隱藏。滑鼠停留時暫停；鍵盤聚焦、全域暫停及偏好減少動態效果時呈現靜態可水平捲動的文字。模組不自行啟動，也沒有逐幀 JavaScript 計時器。
